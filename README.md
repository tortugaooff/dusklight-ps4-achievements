# Build remoto das três conquistas

Copie somente o conteúdo desta pasta para a raiz de um repositório público autorizado. Preserve o arquivo LICENSE e os cabeçalhos de licença. A receita busca as dependências públicas e usa o runner Ubuntu x86_64 padrão. O workflow só executa em repositórios públicos. O limite de disco e a execução integral ainda precisam ser verificados no runner.

O download esperado contém eboot.bin, o preset, recursos do programa, o relatório ELF e hashes. A validação ELF é estrutural. O teste de inicialização, notificações, ícones, menu e persistência depende do Slim. Separe DSKL00002 e confirme que está livre antes de instalar. O disco PAL, a tradução corrigida e o empacotamento ficam no notebook.
